# IA-LAB Workspace

Area para desenvolvimento de IA, experimentos e automacoes.

## Estrutura

- `notebooks`: notebooks Jupyter.
- `agents`: agentes e ferramentas.
- `rag`: recuperacao aumentada por documentos.
- `prompts`: prompts versionados.
- `pipelines`: fluxos de processamento.
- `sql`: consultas e modelos SQL.
- `datasets`: conjuntos de dados locais.
- `experiments`: provas de conceito e comparativos.

Evite versionar dados sensiveis ou grandes dumps sem estrategia explicita.
